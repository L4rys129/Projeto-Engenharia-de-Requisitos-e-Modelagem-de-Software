# 🐾 PetBot

### Sistema inteligente de agendamento para Pet Shops

Um sistema desenvolvido para facilitar o agendamento de serviços como **banho, tosa e consultas**, utilizando um **chatbot** para tornar o atendimento mais rápido, prático e organizado.

---

## 🚀 Sobre o projeto

O **PetBot** foi criado para solucionar problemas comuns no gerenciamento de Pet Shops, como:

* 📅 Conflitos e duplicidade de horários;
* ⏰ Esquecimento de agendamentos;
* ❌ Cancelamentos sem organização;
* 📢 Falta de comunicação entre o cliente e a empresa.

A proposta é centralizar os agendamentos e tornar o processo mais simples tanto para os **clientes** quanto para os **funcionários**.

---

## ✨ Funcionalidades

* 🐶 Agendamento de serviços;
* 🔄 Cancelamento e reagendamento;
* 👤 Cadastro de clientes;
* 🐾 Cadastro de pets;
* 📅 Consulta de horários disponíveis;
* 🔔 Notificações e lembretes;
* 💬 Atendimento por meio de chatbot.

---

## 🛠️ Tecnologias
